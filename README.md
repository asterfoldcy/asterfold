# ASTERFOLD Agency Website

A responsive multi-page creative and digital agency website built with plain HTML, CSS and JavaScript.

## Pages
- `index.html` — Home
- `services.html` — Services
- `portfolio.html` — Portfolio (illustrative concept projects)
- `about.html` — About and process
- `testimonials.html` — Testimonials page with clearly marked placeholders
- `contact.html` — Project enquiry form

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` from this folder.

## Before publishing
Update the contact email in `script.js`, replace testimonial placeholders with real approved feedback, and add the agency's real domain, social links, privacy notice and business details. The contact form opens a pre-filled email draft; it does not store submissions on a server.
